# 版本交付清单

## 1. 交付目标

交付一个可以面向公开用户运行的非收费 MVP，Web 和微信小程序业务功能对等，并具备事实保护、并发控制、链路监测、隐私删除和可复核验收证据。

## 2. 产品与设计

- 主规格和全部子规格；
- Web 高保真页面与状态；
- 小程序高保真页面与状态；
- 两个单栏简历模板；
- 设计 Token；
- Web 与小程序组件清单；
- 空、加载、错误、离线、排队、限额和权限拒绝状态；
- 用户协议、隐私政策、小程序隐私保护指引；
- 埋点字典；
- 30 名用户验证方案和报告模板。

完成定义：页面、状态和组件与功能规格一一对应，没有只有“正常路径”的页面。

## 3. Web

- 营销首页；
- 邮箱验证码登录；
- 用户首页；
- 从零创建向导；
- 导入确认；
- 结构化简历编辑器；
- JD 输入与确认；
- 四类匹配报告；
- 逐条建议；
- 事实库；
- 版本历史；
- 任务中心；
- PDF 预览与下载；
- 账号、隐私、数据导出和删除；
- 桌面、平板、移动响应式；
- Web E2E 和可访问性测试。

完成定义：Web 单独完成两条端到端流程并通过 WEB、FLOW 验收。

## 4. 微信小程序

- 微信主动登录；
- 邮箱绑定；
- 首页与四项底部导航；
- 经历雷达和追问；
- 文件选择、上传、导入确认；
- 分模块结构化编辑；
- JD、匹配和建议；
- 事实库、版本和任务；
- PDF 预览、保存或替代路径；
- 隐私授权、数据导出和删除；
- 分包和包体控制；
- 弱网、后台恢复和真机测试。

完成定义：小程序单独完成两条端到端流程并通过 MP、FLOW 验收。

## 5. FastAPI

- Auth、Users、Facts、Resumes、Imports、Jobs、Matching、Suggestions、Tasks、Exports、Usage、Privacy、Audit 模块；
- PostgreSQL schema 和 Alembic 迁移；
- Redis/Celery 任务；
- Outbox；
- `createApiError`；
- OpenAPI；
- 对象存储签名和生命周期；
- PDF 生成；
- 权限、幂等、事务和删除；
- 单元、集成、契约测试。

完成定义：公开 API 契约稳定，所有 DATA、FILE、SEC 的后端相关项通过。

## 6. Pi AI 服务

- 模型路由；
- 七类 AI 工作流；
- 业务工具白名单；
- TypeBox 输入输出；
- Agent turn/tool/token/time 上限；
- 事实校验；
- retry、fallback、cancel；
- Pi 事件映射；
- token、cache、cost 统计；
- `ai_runs` 和 `ai_trace_events`；
- Prompt/workflow 版本；
- 固定评测集与回归报告。

完成定义：AI 与 OBS 验收全部通过，严重无来源事实为 0。

## 7. 基础设施

- 本地 Docker 开发环境；
- 测试和生产容器定义；
- CDN/WAF/LB 配置；
- FastAPI、Pi、Worker 托管容器部署；
- TencentDB for PostgreSQL、腾讯云 Redis、COS 私有桶与权限；
- 密钥管理；
- OpenTelemetry Collector；
- 日志、指标、Trace 和告警；
- 自动备份；
- 发布与回退流水线；
- 成本阀门。

完成定义：PERF、OPS 验收通过，故障演练有证据。

## 8. 测试与证据

- 单元、集成、契约；
- Web Playwright；
- 小程序自动化和真机；
- AI 固定评测；
- 文件解析和 PDF 样本；
- k6 负载；
- 安全扫描；
- 隐私删除；
- 备份恢复；
- 验收 manifest；
- 最终验收报告。

完成定义：所有 P0 验收项为 PASS，证据 SHA-256 可验证。

## 9. 运行手册

必须提供：

- 本地启动；
- 测试环境部署；
- 生产发布；
- 数据库迁移；
- 回退；
- 模型切换；
- Pi 链路查询；
- 队列积压；
- provider 429/故障；
- Redis/PostgreSQL/对象存储故障；
- 成本达到 70/90/100%；
- 用户数据删除；
- 安全事件；
- 备份恢复。

每份手册包含触发条件、操作步骤、验证命令、停止条件和升级路径。

## 11. 本版本明确不交付

- 支付；
- DOCX 导出；
- OCR；
- 英文；
- 模拟面试；
- 导师和高校后台；
- 自动投递；
- 招聘网站抓取；
- 自主执行系统工具的 Agent。

任何新增项都必须单独修改规格、验收与容量预算，不得以“顺便实现”进入本版本。
