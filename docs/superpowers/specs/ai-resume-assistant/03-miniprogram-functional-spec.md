# 微信小程序功能规格

## 1. 小程序目标

小程序具备与 Web 相同的业务能力，但不复制桌面多栏布局。它使用分模块编辑、底部动作面板和独立预览页完成同一任务。

目标运行环境：

- 微信当前正式版及前一个主要版本；
- iOS 最近三个主要版本；
- Android 10 及以上；
- 典型逻辑宽度 320–430 px；
- 必须在至少一台 iPhone 和两台不同品牌 Android 真机验证。

## 2. 页面与分包

主包只包含：

- 启动、隐私授权、登录；
- 底部导航；
- 首页；
- 我的；
- 轻量错误页。

分包：

| 分包 | 页面 |
| --- | --- |
| `create` | 目标、经历雷达、经历深挖、即时预览 |
| `resume` | 简历列表、模块编辑、版本、预览 |
| `optimize` | 导入确认、JD、匹配、建议 |
| `facts` | 事实库 |
| `settings` | 账号绑定、隐私、数据导出与删除 |

主包和每个分包必须满足微信平台当期包体限制；发布前以开发者工具上传检查结果为准。任何包达到平台限制的 80% 时必须触发构建告警。

## 3. 登录与隐私

- 打开小程序不得静默创建账户；
- 用户点击登录后才调用微信登录能力；
- 首次调用文件选择、剪贴板、保存文件等能力时解释用途；
- 隐私保护指引列出上传简历、教育经历、联系方式和 AI 服务的使用方式；
- 拒绝非必要权限后仍可使用不依赖该权限的功能。

## 4. 首页

包含：

- “我还没有简历”“我已经有简历”两个入口；
- 最近任务；
- 最近简历；
- 当日 AI 用量；
- Web 续接提示，但不把任何功能强制跳转到 Web。

## 5. 经历雷达与追问

- 每屏只显示一个主要问题；
- 选择项最小触控高度 44 px；
- 固定底部显示“上一步”“跳过”“继续”；
- 输入法弹起后当前输入项和主要操作不可被遮挡；
- 每完成一段经历进入全屏即时预览；
- 预览后可确认、编辑事实或继续下一段。

## 6. 导入

支持：

- 微信会话文件选择；
- 本地文件选择能力允许时选择 PDF、DOCX、TXT；
- 粘贴文本兜底。

上传流程：

1. FastAPI 返回短期上传凭证；
2. 客户端直接上传私有对象存储；
3. 上传完成后调用确认接口；
4. 后端校验哈希、大小和 MIME；
5. 创建解析任务并返回 `task_id`。

小程序不在本地解析完整简历。进度页可离开，任务完成后通过任务中心继续。

## 7. 结构化编辑器

### 7.1 导航

编辑器首页按模块显示：

- 模块名称；
- 完整性状态；
- 条目数量；
- 事实风险数量；
- 拖动手柄替代方案“上移/下移”。

点击模块进入独立编辑页。每次只编辑一个模块或一个条目。

### 7.2 编辑能力

与 Web 一致：

- 增删模块和条目；
- 修改字段与要点；
- 排序；
- 查看事实来源；
- 接受、编辑、忽略建议；
- 撤销最近操作；
- 自动保存；
- 冲突处理；
- 历史版本恢复。

小程序不要求跨多个页面保持一个原生拖拽操作。排序可以使用“上移、下移、移到顶部、移到底部”，结果必须与 Web 一致。

## 8. 匹配与建议

匹配报告使用四个可折叠分组。每条要求显示证据标签。

建议详情使用全屏页或底部抽屉，包含：

- JD 要求；
- 原文；
- 建议；
- 理由；
- 事实来源；
- 风险；
- 接受、编辑、忽略。

接受后立即更新服务端版本并返回新的 `version_id`。

## 9. 预览与导出

- 预览使用服务端生成的低分辨率分页图片或安全 PDF 预览地址；
- 支持页间滑动、适宽和整页；
- 导出请求与 Web 使用相同接口；
- 成功后支持打开、保存到本地或转发系统文件；
- 若平台不允许某项文件操作，必须展示替代方式，不得把导出功能标为成功。

## 10. 网络与生命周期

- `onHide` 时提交未保存编辑；
- `onShow` 时刷新任务和版本状态；
- 网络断开显示全局离线状态；
- 本地草稿使用加密或平台安全存储，不保存完整上传文件；
- 本地草稿最多保留 7 天，成功同步后立即删除；
- 请求超时不得自动重复提交非幂等操作；
- 所有写操作携带 `Idempotency-Key`。

## 11. 性能

- 冷启动到首页可操作 P75 ≤ 2.5 秒；
- 分包页面首次打开 P75 ≤ 2 秒；
- 页面切换 P75 ≤ 500 ms 显示骨架或内容；
- 300 条事实、20 份简历时列表滚动无明显阻塞，连续操作 30 秒内无超过 200 ms 的主线程卡顿；
- 单次本地保存的数据量 ≤ 200 KB。

## 12. 小程序测试证据

必须提交：

- 微信开发者工具上传检查结果；
- 主包和各分包大小报告；
- 自动化两条端到端流程日志；
- iPhone、华为/荣耀、OPPO/Vivo/小米中至少两个 Android 品牌的真机视频；
- 弱网、断网恢复、后台 5 分钟后返回的状态恢复录像；
- 文件选择、上传、预览、保存和失败替代路径证据；
- 隐私接口与实际调用能力清单对照。
