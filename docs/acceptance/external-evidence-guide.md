# 外部验收证据指南

本地脚本不能替代外部证据。以下项目在证据缺失时必须是 `BLOCKED`：

- 微信开发者工具包体报告、1 台 iPhone 与 2 个 Android 品牌真机、冷启动/分包 30 次原始 trace、弱网和后台恢复录像；
- Chrome/Edge/Safari 当前与前一主版本矩阵、Lighthouse 和生产样 Web Vitals；
- 腾讯云 VPC、TLS、至少两个 API 副本、金丝雀、告警送达、COS 清理清单；
- 真实模型供应商账单、回退和数据保留政策；
- 隔离环境备份恢复的 RPO/RTO 记录；
- 30 名目标学生的任务成功率和访谈记录。

每份证据必须记录 UTC 时间、候选 `commit_sha`、环境/设备/版本、原始文件和 SHA-256。视频必须同时配 API 或数据库断言；截图不能单独证明写入成功。证据先脱敏，再放入候选 release 目录，然后重新运行 manifest hash 校验。
